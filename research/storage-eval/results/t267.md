# B-cli against B (T267)

`bench.js --option B-cli` runs the real CLI of this tree on `state.db`, migrated by its first command from a copy of the live state (2026-10-17: a 92 MB log, 67k state events, 403 tasks). `--option B` runs T255's prototype on the same tasks and events; `prepare.js --cli` builds both. Each pair ran back to back, B first, on the shared 24-core rig.

## Rerun, 2026-10-24, after merging main

A copy of the live state on 2026-10-24: a 162 MB log of 146k events, 565 tasks, a 19 MB `tasks.json` and a 758 KB `project.json`. The file layout is `main` (A-cli, `--a-tree` a checkout of `main`); B-cli is this branch. Quick runs (`--quick`), three of each, on the shared 24-core rig at load 8 to 28. Median of 3 runs (min..max). Raw results are in `raw-t267/`.

| option | hook p50 / p95 ms | mutation p50 / p95 ms | kill -9: acked writes, lost |
|---|---|---|---|
| A-cli (`main`) | 939 (817..1106) / 1223 (918..1325) | 3588 (3113..7345) / 9606 (5911..11335) | 19, 0 |
| B-cli | 47 (40..64) / 58 (45..138) | 148 (145..165) / 314 (237..2336) | 793, 0 |

Hook p95 is 21x lower and mutation p95 31x lower. Every B-cli kill cycle left an `integrity_check` of `ok`, no task change without its event and no inbox row out of step with the log. Migration, the first command of each B-cli run, took 3.0 to 5.8 s.

One command at a time on the same copy, five runs each through `/usr/bin/time` (median wall time and peak RSS, min..max), with `main` at f416404a and this branch after migrating the copy, at load 32 to 37:

## Where B-cli spends its time

A B operation is one storage call. A CLI command also boots Node (13 ms), loads its modules (about 13 ms), parses and checks all 403 task heads, and holds the state lock for 14 ms at p50 against B's 4 ms. Under seven writers, waiting for that lock sets the mutation p95.

## Reproduce

```sh
node prepare.js --src <copy of the state directory> --out <datasets> --only live --cli
node bench.js --option B --dataset live --run 1 --datasets <datasets> --work <work> --a-tree <this tree> --out B.json
node bench.js --option B-cli --dataset live --run 1 --datasets <datasets> --work <work> --a-tree <this tree> --out B-cli.json
node summarize.js <dir with both> <out>
```

`BENCH_LOCK_TRACE=FILE` has every CLI command log its lock holdings (`TOWER_CRANE_LOCK_TRACE`).
