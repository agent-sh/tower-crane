- Tests no longer signal pid 0. A test that read a pid file before its writer finished got `Number('')`, which is 0, and `process.kill(0, 'SIGKILL')` killed its own process group. In the tests gate that killed the whole base rerun, with no teardown. `test/signals.js` adds `killPid` and `killGroup`, which refuse anything that is not a process id; every test signal to another pid goes through them, and `npm run check:shared` rejects a bare `process.kill` on any pid but `process.pid`. Fixtures that write a pid a test signals publish it atomically.
- The tests gate reports a base rerun killed by a signal. The failure records `base_rerun_killed: {base, signal, status}` and no `confirmed_failure`, its summary says the shared failures were not checked, and automation retries it once like a timeout. Before, the killed rerun found no shared names and the head's failure was confirmed as if the base had been checked.
