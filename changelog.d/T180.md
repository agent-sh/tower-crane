- `worktree` in a sandboxed worker prints the worktree its spawn made and takes no state lock. It no longer refreshes stacks or records a branch there, so a worker in a repository with a linked stack no longer fails with a read-only lock. A sandboxed worker asking for a worktree that does not exist is refused; dispatch prepares it. The read applies only to the broker's own state directory, so an inherited broker variable does not stop `worktree` in another state directory, such as a test fixture's.
