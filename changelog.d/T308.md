- Tests read files that fixtures publish by rename through `readPublished`, which waits out the brief EPERM, EACCES or EBUSY that Windows returns while a rename replaces the file or its removal is pending. A detached record read during that window was a test failure. A lint test sends every reader that treats a missing file as not written yet through it, whether it catches ENOENT or checks `existsSync` on the same path first.
- The live-fallback rework test ties each wait to the spawn's supervisor and always releases its worker, so a fallback that never starts fails in seconds with the wait's message instead of the 300 s runner timeout.
