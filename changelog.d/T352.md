- The gc.recentObjectsHook row in the git config tests passes on git 2.56. Since git 2.54 auto-maintenance defaults to the geometric strategy, which has no gc task, and git 2.56 raised its loose-object threshold from 100 to 6700, so plain git no longer ran the hook. The row now sets `maintenance.gc.enabled`, so plain git runs the hook on every version and the check that Tower Crane git does not run it keeps its meaning.
