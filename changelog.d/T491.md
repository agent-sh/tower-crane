- A code task's review now runs before its tests gate. Cleanup, sources and CI run first, the reviewer is dispatched, and the full suite runs only after the review passes. A failed review goes to rework without a suite. Set `review.tests_first: true` with `project set --review-policy` to run tests before review as before. A reviewer the host governor deferred is retried, and `status` shows no blocker, while its tests gate waits for that review. `status` lists such a task under `waiting on review`.
