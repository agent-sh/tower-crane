- Workers merge the base at first publish, on a reported conflict or on request. They check fixes locally and publish the submitted head once, immediately before submit, including rework.
- Submit records `pushes_since_last_submit` from distinct PR heads observed by Actions runs plus the current head. Counts above one produce a warning and appear in status. Unavailable history records a null count and an error. This observed count can undercount or overcount pushes: heads that start no Actions run can be missed, and a late run for a head replaced before the previous submit can be counted in the next interval. Run creation time is not push time, so the warning calls for inspecting the history and does not prove multiple worker pushes in that interval.
- Branch history includes engine and orchestrator pushes. Status omits accepted and cancelled tasks. History queries use whole seconds with exact submit-time filtering, and a gh policy refusal records an informational note instead of a warning.
