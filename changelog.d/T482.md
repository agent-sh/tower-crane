- On Windows, a budget, interrupt or supervision stop whose `taskkill` fails or outlasts its timeout now stops the harness through its own process handle. The supervisor stopped an agent once and never again, so such an agent ran on until it exited itself. Broker and gate tree stops use the same fallback, and a gate's stop no longer waits on `taskkill` without a timeout.
- Tests: the simulated Windows file ids round a Number ino once, from the exact id, and the 0.1.2 manifest tests inject an id that rounds and one that does not. The governor tests stop their `wait --follow` children and release their units before fixture cleanup removes the directory those write.
