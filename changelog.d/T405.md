- A host resource governor admits every agent dispatch, heavy gate (tests, clean, local CI) and merge-queue suite against one memory budget that every Tower Crane project of the user on the host shares through a per-user registry. It reads the cgroup chain up to the shared slice, host memory and swap, memory and CPU pressure, and load. It keeps room for running units to grow and for other sessions to return to their recent peak.
- Deferred work refuses with code 3 and its reason, shows in `status`, `inbox` (`governor_deferred`) and the board, and a `wait` retries it once there is room. Past the stop line Tower Crane stops its own running work, gates and suites before reviewers before workers, newest first. It never signals a process it did not start. A stopped gate records no verdict, and a stopped worker resumes in its kept worktree.
- `project set --governor JSON` sets the defer and stop lines, pressure and load lines, the other sessions' window and the expected unit sizes (docs/state.md#host-resource-governor). `scripts/governor-stress.js` runs three projects and an outside memory hog inside a small systemd scope.
