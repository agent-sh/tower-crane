- Claude's sandbox can leave empty, read-only mount points for denied dotfiles (`.bash_profile`, `.bashrc`, `.gitconfig`, `.idea`, `.mcp.json` and the `.claude` entries, among others) in a worker's worktree root. Spawn gives those absent paths a private `core.excludesFile` for the Claude process, so `git status` does not list them while the agent runs, and the monitor removes the newly created empty, read-only regular files after each attempt. Pre-existing files stay visible and untouched, and symlinked parents are refused before any cleanup. The placeholder names never enter the shared `info/exclude` or the repository `.gitignore`.
