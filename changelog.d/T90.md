- Claude's sandbox can leave empty, read-only mount points for denied dotfiles (`.bash_profile`, `.bashrc`, `.gitconfig`, `.idea`, `.mcp.json` and the `.claude` entries, among others) in a worker's worktree root. Spawn gives those absent paths a private `core.excludesFile` for the Claude process, so they never show in `git status`, and the monitor removes the newly created empty, read-only regular files after each attempt. Pre-existing files stay visible and untouched, and symlinked parents are refused before any cleanup. The shared `info/exclude` and the repository `.gitignore` are not changed.
- Spawn receipts and job files go under `XDG_CACHE_HOME` when it is set, as the agent caches already do, instead of always under `~/.cache`.
