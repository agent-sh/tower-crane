- Tests evidence binds the effective `tests.paths`, `tests.keep` and `tests.expensive` settings alongside its pinned commands and mode. Each receipt and its audit event record them in `gate_policy`, captured when the check starts. Changing any of them makes a previous pass stale in task reports, acceptance and merge, including a change made while the tests gate runs. Evidence checked before this release has no snapshot of these settings, so it needs a new `check tests`. Unrelated settings such as `gates.executors` keep evidence valid.
