- Gate worktrees follow the project setting `gates.tmp_root` (`project set --tmp-root DIR`) instead of only `TOWER_CRANE_TMP` or the system temp directory. `check tests`, `check ci` (local CI) and `check clean` build their worktrees under it; `TOWER_CRANE_TMP` still overrides it. Gate evidence records the root it used, `project show` prints the setting, and `status` prints the root in use with what chose it.
