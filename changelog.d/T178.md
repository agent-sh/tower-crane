- The worker skill runs the reviewer's checklist on its own diff before `submit`, at the PR head: each acceptance item probed, each claim checked, revuto and CI read at the head. The result goes in a `## Pre-submit review` section of the PR body. A fresh-context subagent is used where the dispatch allows one.
- `submit --precheck pass|fail|skipped` records that result on the `submit` event as `precheck`. It is a measurement record only: no gate reads it, and a submission is never refused for it.
