- With `sandbox.session_bus` on, a codex agent whose runtime directory lies outside `/run` under a readable path, such as `/var/tmp`, now sees only the bus socket there. Before, the profile hid the runtime directory's other entries one by one at spawn, so a socket made there later was reachable. The readable rule that exposed the directory now gives way to its entries on the way down, and the runtime directory is not mounted. claude already denied the whole directory but the socket.
