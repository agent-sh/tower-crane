- A placeholder cleanup marker records the boottime offset of its holder's time namespace, and a cleanup corrects the recorded start time by it. A live holder under `unshare -T --boottime N` is no longer judged gone.
- When an agent's process group ends, the supervisor's placeholder cleanup tries again for 1 s while a shim its sandbox outlives still holds the git directory.
- `docs/state.md` notes that on hosts outside the initial pid namespace (WSL2, LXD, devcontainers) a marker under another host name is never judged and needs removing by hand.
