- Every skill path an agent is given now points into its own tool snapshot, `homes/<agent>/tool/skills/`. This covers rework, interrupt and review prompts, claude and codex instructions, the codex, opencode and agy skill links, and pi's `--skill`. Before, they named the dispatcher's package root. When automation dispatched from inside a worker's monitor, that root was the worker's snapshot, so a reviewer was told to read a file that was removed when the worker exited, and a codex reviewer's linked skill dangled.
- The tool snapshot takes `skills/` from `TOWER_CRANE_PLUGIN_ROOT` when it is set.
- When the role skill is missing, the prompt names it without a path, and spawn still warns.
