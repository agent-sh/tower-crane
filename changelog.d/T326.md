- Every skill path an agent is given now names a copy in the state directory's skill store, `skills/<key>/`, keyed by the skills' content and never removed. This covers rework, interrupt and review prompts, `reviews/<task>-<sha>.md`, claude and codex home instructions, the codex, opencode and agy skill links, and pi's `--skill`. Before, they named the dispatcher's package root. When automation dispatched from inside a worker's monitor, that root was the worker's tool snapshot. A reviewer was then told to read a file that was removed when the worker exited, and a codex reviewer's linked skill dangled. The store is outside `homes/`, which the claude and codex sandboxes hide even from the agent itself, so both can read it with their own tools and their shell.
- The light claim-check review packet now names the review skill in its first line, as the full packet does.
- When the role skill is missing, the prompt names it without a path, and spawn still warns.
