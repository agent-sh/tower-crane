- Review dispatch reads revuto's open inline comments on the PR, lists them with path, line, body and `[P1]`/`[P2]` marks in the reviewer's packet and records them on the reviewer spawn, with whether each finding's file changed since the comment. Findings also stay in the prompt when a large diff is supplied by file. A review ok is refused, naming the comment, while a recorded `[P1]`/`[P2]` has neither an explicit resolution nor such a change. The latest non-revuto reply must begin with `[resolved]` on a line of its own; discussion, quoted markers and later unmarked replies leave the finding open. The resolution signal is recorded separately from the reply id, so older snapshots cannot clear a finding with a reply id alone. The check reads only the state, so it holds for brokered reviewer evidence too.
- The resolution gate regression submits natively and runs both reviewers in the foreground, keeping automatic review dispatch from competing with a second snapshot.
- Windows CI test jobs use a 45-minute budget so shards can finish beyond the former 15-minute limit. Linux jobs retain their 15-minute budget, and each test retains its five-minute deadline.
