- An environment value is redacted under the splits that still showed part of it: a value whose head a line-split token takes, split by a real two-character escape, and a value whose characters an escape would take, as `ESC [` before a letter or digits, `ESC (` before `.` or `-`, or an OSC the value goes on in. The text path redacts the whole value, and a binary artifact holding one is not copied.
- A binary artifact holding a token that a real two-character escape and a line break both split, such as `ghp_Ab3dEf\x1b(B6hIj9kLm2nO\np5q...`, is not copied. Before, no view of the bytes joined it.
