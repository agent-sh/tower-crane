- A sandboxed claude agent in a project at a deep path reaches its state broker again. When `brokers/<agent>/broker.sock` is too long for a socket address, the socket now goes in the agent's own temp directory, which only its sandbox reads, then in a private directory in `/tmp`. It used to go under the caller's temp dir or `~/.cache`, which the sandbox hides with the home, so every brokered command failed with `cannot reach the state broker ... (ENOENT)`. With no such path, spawn fails at the start and says why.
