- A live state broker keeps its socket where its agent finds it. Code in the agent's sandbox could remove the socket and owner record from the agent's socket directory: a test run from a tree older than T502 swept them, since the monitor's pid is missing in the sandbox's pid namespace, and the worker could no longer push or submit. The broker now watches the directory and listens there again, writing its owner record again.
- When the socket directory itself is gone, the supervisor stops the agent and records `blocked` with the reason `state broker lost: its socket directory <dir> is gone`, instead of leaving it running unable to reach its broker.
