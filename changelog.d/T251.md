- Host-only tests in the tests gate no longer fail when the gate temp root is deep. Claude Code's Linux sandbox puts its bridge socket in `TMPDIR`, and a 78-byte gate scratch pushed it past the 108-byte socket path limit ("Failed to create bridge sockets after 5 attempts"). Each separate host-only command now gets a short `TMPDIR` under `~/.cache/tc-XXXXXX` (or `XDG_RUNTIME_DIR`) when the scratch is over 73 bytes, removed afterwards. With no short directory writable, the gate refuses up front and names `gates.tmp_root`.
