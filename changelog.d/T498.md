- Tests and hosted CI compare named failures with the newer complete daily or merge-base CI run per workflow, bounded by the merge-base commit time. Matching base failures pass their part with run, test and first-error evidence; new failures still rework. Excluded base failures cannot supply reverted-test proof.
- A known flake rescued by the gate's single rerun records `known_flake`; a twice-failing flake keeps its failure. Each excluded test opens or updates one open fix task, using explicit test identities, including open flake tasks. Closed flake fixes return later flakes to the repeat-flake ledger. Status shows source tasks, base runs and fix-task links.
