- A spawned agent's command that starts before its dispatch records the spawn waits for that record, up to the supervisor's startup window, before it resolves its role. An orchestrator's early `wait` now registers as a controller instead of running unregistered, where natural-exit cleanup killed it and its home could be pruned.
- Controller-home fixtures count only a renamed registration record, fail at once when the controller exits before it registers, and report a missed registration before the test's own timeout.
- The retrying-home supervision test waits for the `spawn retry` record instead of asserting it once the retried harness reports ready. The supervisor launches a rerun inside the mutation that records it, so a loaded machine let the harness run ahead of the commit; a fixture now holds that commit to make the order certain.
- The test of a group member that ignores SIGTERM no longer races the supervisor's SIGKILL deadline. Its fixture held the group SIGKILL for a fixed second of that two-second deadline, so a supervisor stalled on a loaded machine failed with "did not stop after SIGKILL". The kill now lands once the supervisor has seen the group still there, and a row that stalls the supervisor's clock after the kill covers it.
