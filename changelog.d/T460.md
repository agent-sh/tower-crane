- The tests gate reruns a failure's files once when every failing test shows a child ended by SIGSEGV, SIGBUS or SIGILL with empty output, judging a suite or parent test that failed only through such tests by them. A passing rerun passes the gate, and its `receipt.reruns` entry lets the evidence count. Each crash is recorded as `native_crash` with its test, signal and pid, and `status` counts the last 7 days. Where apport keeps cores, gate commands run with a raised core limit; a crashed child's core moves to the task's private scratch, gdb reads its stack into the evidence, and the core is deleted.
