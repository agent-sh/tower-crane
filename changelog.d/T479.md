- Windows CI shards run through `scripts/shard-guard.ps1`, a watchdog outside node. It runs the tests in a Windows job object with process and memory limits, and posts the shard's progress every minute as a neutral `shard progress (...)` check run, so a frozen runner still leaves its last state on GitHub. At 38 minutes it dumps the job's processes with handle and memory counts, stops them with `taskkill /T /F` and the job, and fails the step so the progress artifact still uploads. A `hang` run on Windows now proves this guard instead of node's watchdog.
