- `tests.host_only` lists test globs that cannot run inside a worker sandbox, where root-owned host files appear as uid/gid 65534. Set it with `project set --tests-host-only`. The worker brief names them, every spawned role gets them in `TOWER_CRANE_HOST_ONLY`, and a sandboxed run skips the matches in a runner that honors it (this repository's `test/run.js` does). While the list is set, this repository's `test/run.js` refuses a directory or glob selection in a sandboxed run, since Node would expand it past the skip. The tests gate always runs them on the host: it sets `TOWER_CRANE_SANDBOX=0` and drops the list for its commands.
- The state and worker docs now state the sandbox limit: no root mapping, and gate commands run on the host, outside the sandbox.
