- `project set --session-bus true` (owner-required, off by default) lets claude worker sandboxes reach the user's session bus socket (`$XDG_RUNTIME_DIR/bus`), following the worker's environment, including the project's `env` and `env_file`. A command that uses the bus can start user units outside the sandbox, so the grant lifts confinement for the project; docs/state.md says what it reaches. It does not let `systemd-run --user --scope` start inside claude sandboxes: the user manager socket stays denied, and a live run that granted it still failed.
