- `project set --session-bus true` (owner-required) lets claude worker sandboxes reach the user's session bus and user manager socket (`$XDG_RUNTIME_DIR/systemd/private`, which `systemd-run --user --scope` connects to), so scopes work inside them. Off by default. A unit started through either runs outside the sandbox as the user, so the grant lifts confinement for the project; docs/state.md says what it reaches.
