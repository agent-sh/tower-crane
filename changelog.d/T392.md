- A header that an escape glues to a token or a word keeps its value redacted. `z xoxa-ab\ncdefghij\x1b(B\x1b[1mAuthorization: Bearer x` showed `x`: the cleanup removed the escapes, the token's run took the header word, and no pattern found the header. Such a header is now read with a space before it, and the header word goes back from the token when the token stays whole without it. A binary artifact with such a header value is not copied. The value is redacted to its end however long it runs, and a line of glued headers is read in one pass.
