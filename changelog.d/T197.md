- `tower-crane ci log JOB_ID [--failed-tests]` reads one CI job of the task's own PR while its run is still going. It writes the log without ANSI escapes under the task scratch and, with `--failed-tests`, names each failing test with its first error line. A job outside a check run on the PR head is refused.
- `tower-crane ci alerts` lists the open code-scanning alerts on the task's PR head.
- Workers reach both through the state broker, so they no longer wait for a whole run or ask the orchestrator to fetch logs. The worker and orchestrator skills say to use them.
