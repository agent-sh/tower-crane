- Hooks no longer stall or fail a harness turn on a busy state lock. Tool progress goes to `progress/<agent>.jsonl` without the lock. A prompt with nothing pending reads only the event log, and a prompt with messages pending tries the lock once and leaves them for the next hook.
- Settled evidence fields over 1 KiB move to `evidence/<task>/<sha256>.json` on the next write, so `tasks.json` no longer grows with gate output. Evidence at a task's current head stays inline, which keeps older pinned tools' gate decisions unchanged. On this project, `tasks.json` went from 33 MB to 9.4 MB and the median write from 1,028 ms to 415 ms.
