- The CI shard deadline runs in a detached watchdog process, so a shard whose runner event loop is blocked is still dumped, stopped and failed. The test step has a 40-minute limit under the 45-minute job limit, and every test job uploads its file progress and the watchdog's log, with free memory, load and the process dump, as a `shard-progress-*` artifact on every outcome. A manual CI run with the `hang` input blocks every shard runner to show it.
