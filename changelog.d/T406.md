- The git and gh shims stop with exit 127 and `git shim loop: <program> leads back to this shim` when a program on PATH ahead of the real git or gh runs the shim again. Before, a test's wrapper inside an agent recursed without end and filled the host with processes. A shim read that times out now kills its whole process group, so nothing it started keeps running. The ladder and git-config tests resolve the real git past agent shims.
