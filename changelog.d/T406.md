- The git and gh shims stop with exit 127 and `git shim loop: <program> leads back to this shim` when a program on PATH ahead of the real git or gh runs the shim again. Before, a test's wrapper inside an agent recursed without end and filled the host with processes. On Linux, a shim read that times out now kills every process it started, and the read stays in the agent's process group, so stopping the agent stops it too. The ladder and git-config tests resolve the real git past agent shims.
