- A head that only merges the advanced base into a gated head keeps that head's tests, clean and review results. It keeps the revision and starts no new tests or review run. CI is still read at the new head.
- A head whose merge resolved conflicts, with the same own change, gets a review of the resolution only, against git's automatic merge, when the review at the earlier head passed. When the earlier head's tests passed, its tests gate runs only the tests the `tests.map` selection names for the resolved files (with `tests.crucial` in crucial mode), plus the declared host probes. A test file that fails there is rerun once on its own, as on any other head. This also holds for the head a worker submits after automation sent a conflicting PR back.
- A re-review after the worker merged an advanced base narrows to the worker's own new lines when the reviewed change merges cleanly with the new base. A reviewed change that conflicts with the new base still gets a full review.
- `task show` and `status` name a carried result as `carried from <sha>: base-only head`.
