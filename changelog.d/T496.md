- A head that only merges the advanced base into a gated head keeps that head's tests, clean and review results. It keeps the revision and starts no new tests or review run. CI is still read at the new head. A conflict rework's next head can keep them too.
- A head whose merge resolved conflicts, with the same own change, gets a review of the resolution only, against git's automatic merge. Its tests gate runs only the `tests.map` tests for the resolved files.
- A re-review after the worker merged an advanced base narrows to the worker's own new lines instead of falling back to a full review.
- `task show` and `status` name a carried result as `carried from <sha>: base-only head`.
