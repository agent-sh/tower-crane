- The host governor counts other sessions per level. Each sample names the level it was taken against, and each level keeps room only for its own samples and counts only the units inside it. A `wait` in a terminal's scope no longer defers every dispatch from a spawned orchestrator's scope by the gap between the two levels' use.
- A finished agent gives up its governor place. Its supervisor removes the unit once the harness has exited, before its gate reactions run, and an agent with no running harness is never a stop victim. The governor no longer kills a supervisor mid-reaction or reports `governor_stopped` for a worker that already submitted.
- On Windows the governor records each process's creation time and checks it before every stop. A pid Windows gave to another process is never signalled, a unit whose holder's pid was reused is dropped instead of stopped, and a pid recorded without a creation time is never signalled.
