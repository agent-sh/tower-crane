- A sandboxed agent can fetch from an ssh or private https origin. Its `git fetch origin` goes through its state broker, which fetches with the user's login on the host and sends back the base, the stacked base and the task branch with a thin pack of what the agent lacks. The shim indexes the pack into the task repository and updates `origin/<branch>` and `FETCH_HEAD`. Before, fetch failed in the sandbox: no credential, no SSH agent behind the hidden `/run`, and ssh refused its own config files as "Bad owner" when root-owned files appeared owned by nobody. The broker fetches only from the project's recorded GitHub repository and refuses other branches; a local origin is still fetched in the sandbox. `git pull` from such an origin is refused with the fetch-then-merge way that works.
