- Bound dispatched CI runs per repository with `ci.max_dispatches` (default 2). Overflow requests queue, newer branch heads replace queued requests, and host automation starts them as capacity frees. Status shows runs in flight and queued requests.
- Group manual CI runs by branch and cancel older dispatched runs when a newer run starts; profile and hang runs keep groups of their own. Main push, tag and schedule concurrency stays unchanged.
- Release reservations for deleted dispatch runs and keep queue errors from suppressing PR completion webhooks.
