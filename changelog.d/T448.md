- Local CI can preserve `ci.local.receipts` globs in hidden `ci-artifacts/` before removing its worktree, on pass or fail. Copies use the log's run name and stay private to the owner and orchestrator. Agents receive failed step labels, exit and timeout details, run-state reasons and copied references. Joined diagnostic fields are checked for split credentials and replaced with an omission notice when unsafe. Copies are capped at 8 MiB per file with a truncation notice.
