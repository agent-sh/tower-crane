- Codex agents no longer reach the caller's TMPDIR or the host's `/tmp`. codex resolves its `:tmpdir` permission from the TMPDIR it starts with, and Tower Crane passed the caller's, so with TMPDIR under the home every sandboxed codex agent could read and write other tasks' scratch and test fixtures there. `:slash_tmp` gave it the host's `/tmp`, shared with every other process. Each sandboxed codex agent now gets `tmp` inside its writable cache (the task scratch for a worker) as its TMPDIR, and its permission profile names that directory instead of `:tmpdir` and `:slash_tmp`.
