- Codex agents no longer reach the caller's TMPDIR. codex resolves its `:tmpdir` permission from the TMPDIR it starts with, and Tower Crane passed the caller's, so with TMPDIR under the home every sandboxed codex agent could read and write other tasks' scratch and test fixtures there. Each sandboxed codex agent now gets `tmp` inside its writable cache (the task scratch for a worker) as its TMPDIR, and its permission profile names that directory instead of `:tmpdir`.
