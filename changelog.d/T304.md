- The stacked-PR gh stub no longer loses a stack link. Each gh call wrote back the whole copy of its state file that it read, so a reviewer's `gh pr view` that read before an observer's `gh stack link` and wrote after it reset `linked` and `order`. The detached spawn test then saw the task linked and an empty stack order. A call now applies only its own changes to the current file under a lock file, through `updateJson` in `test/atomic-file.js`, and the test fixture and the stub worker write the file the same way.
