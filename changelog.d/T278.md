- The browser test kit removes a Chrome profile only after Chrome's whole process tree has exited. Chrome's network service writes its cache index and state into the profile on its way out, so a helper that outlived the browser recreated a removed profile. Teardown now signals every process in the tree and waits for each to go. The exit fallback kills the tree and waits for it before it removes the profile, where it used to kill only the browser and leave a recreated `Default` directory behind every time.
