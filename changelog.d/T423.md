- Containment probes use `systemctl --user` and all outer scopes use `systemd-run --user --scope`, which connect to the systemd private socket as peers without bus-daemon `Hello`.
- Probe and scope wrappers receive the same resolved runtime directory when `XDG_RUNTIME_DIR` is unset or empty, then restore the command's original environment. A missing or stale session bus does not break a reachable private manager. The sweep, `Result` read, `kill` fallback, settle reset and keeper reach the manager through that same runtime directory.
- Cache manager availability per process and transport environment, and omit the fence key from outside-caller warning metadata.
- Callers outside their own user manager need confirmed linger for a new scope. Otherwise automatic containment uses the process/RSS watchdog and warns about logout; explicitly configured outer scope properties refuse unsafe placement before launch.
- Pass `--expand-environment=no` to `systemd-run` only from systemd 254, which added it. Earlier versions never expand `--scope` arguments, so on systemd 249 to 253 every launch keeps its kernel scope and configured `scope` properties no longer refuse. An unreadable `systemd-run --version` selects the watchdog before launch.
