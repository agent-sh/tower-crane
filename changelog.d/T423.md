- Containment probes and scope registration use the systemd private socket in the launch environment, so a missing session bus or stale `DBUS_SESSION_BUS_ADDRESS` no longer breaks agent and gate launches.
- Configured outer scopes give `systemd-run` the probe's resolved runtime directory when `XDG_RUNTIME_DIR` is unset or empty, then restore the command's original environment.
- Callers outside their own user manager need confirmed linger for a new scope. Otherwise automatic containment uses the process/RSS watchdog and warns about logout; explicitly configured outer scope properties refuse unsafe placement before launch.
