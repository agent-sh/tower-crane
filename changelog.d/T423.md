- Containment probes use `systemctl --user` and all outer scopes use `systemd-run --user --scope`, which connect to the systemd private socket as peers without bus-daemon `Hello`.
- Probe and scope wrappers receive the same resolved runtime directory when `XDG_RUNTIME_DIR` is unset or empty, then restore the command's original environment. A missing or stale session bus does not break a reachable private manager.
- Cache manager availability per process and transport environment, and omit the fence key from outside-caller warning metadata.
- Callers outside their own user manager need confirmed linger for a new scope. Otherwise automatic containment uses the process/RSS watchdog and warns about logout; explicitly configured outer scope properties refuse unsafe placement before launch.
