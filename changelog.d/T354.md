- A gate run's lease deadline now covers every timed command the run may start. A prove-mode tests run counts its head run, the scoped proof under `tests.expensive`, the reverted run, a base rerun and one command per host-only file in each of the first three. Before, the deadline allowed one command timeout and a minute, so on macOS and Windows, where no start ticks prove a holder alive, a second caller treated a healthy long run as ended and ran the gate again.
- A test covers a run whose orchestrator lease is taken over mid-run: the guard refuses its evidence and its lease's error write, and the lease still ends as engine bookkeeping.
