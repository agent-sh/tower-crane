- Workers can declare host measurements with repeatable `submit --host-probe CMD`. The tests gate runs them at the submitted sha with gate resource caps, host environment settings and a configurable 10-minute timeout per probe. Evidence and reviewer prompts carry status, duration and redacted output; failures return through rework. Changing the probe list at the same commit advances the task revision so an old run or verdict cannot judge its replacement.
- Worker and orchestrator guidance leaves cleanup to the clean gate and declares pending host results in the PR body without opening a decision.
- Signal kills, resource-cap interruptions and wait shutdown during host probes get one automation retry before rework. Normal nonzero exits and timeouts still return directly through rework.
