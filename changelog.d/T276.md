- Sandboxed claude commands reach GitHub and the npm registry again. The claude profile set `network.allowedDomains: ["*"]`, which Claude Code refuses as too broad, so its proxy allowed no host and every https request from a sandboxed command failed with `Proxy CONNECT aborted`. The list now names GitHub's hosts, `registry.npmjs.org` and the hosts of the repository's remotes, and the new `sandbox.domains` setting (project and rung, owner-required) adds more. A pattern claude would refuse is refused at `project set` and at spawn.
