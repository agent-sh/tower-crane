- A worker that asks and releases its task keeps its branch and PR link. `release --pr N` links the open PR it opened, checked as `submit` checks it, so answering the decision makes the task ready on that PR and the next worker resumes it instead of opening another. A task linked to a closed or merged PR moves to a new one the same way. A release by someone other than the claimant that needs the owner no longer links the PR before the owner approves. `rework` now sends back a todo task released for a decision, answered or not; a todo task released without one still refuses it.
