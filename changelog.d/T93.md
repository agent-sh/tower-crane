- Live spend: the supervisor reads each running agent's usage from the harness's own session data (claude session JSONL, codex rollout, opencode and pi logs) every `supervision.usage_ms` (default 30 s) and records it under the exit collector's key, which replaces it at exit so nothing counts twice. Harnesses without live data show `unavailable`, never zero, and readings older than ten intervals show `stale` in `status`, `task show` and the board. Project and new per-task budgets (`task update --budget-tokens`, `--budget-hours`) are enforced on live usage: a crossing stops the agent (`budget.stop`, operational), opens an owner decision to raise the budget (`budget.raise`, owner-required) and spawn refuses until it is raised.
