- Test fixtures and harness stubs write the files tests poll through a rename, so a reader under load never finds them empty or half written. This fixes "Unexpected end of JSON input" and "Unterminated string in JSON" flakes, such as the fallback attempts file, and the empty hook pause signals that `waitFor` returned. `fileWritten(file, { json: true })` and `waitFor(file, { json: true })` wait through a file still being written, and a test fails on a fixture that writes polled content without the helper.
