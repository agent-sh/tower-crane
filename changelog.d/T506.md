- Every spawned agent runs `tower-crane` from its pinned tool snapshot before any global install, on POSIX and Windows. Spawn refuses when it cannot provide the shim. The pinned CLI's `--version` includes its commit, or `unknown` for a package without Git metadata. Child dispatches from a spawned orchestrator use its snapshot; respawn the orchestrator from an upgraded CLI to use the new version.
- Generated-conflict tests wait for a fresh reconciliation to drain before checking the repaired head, including when the first startup pass defers its work.
