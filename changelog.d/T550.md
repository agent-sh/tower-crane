- A passing local CI receipt survives a base move when the project's new `ci.overlap` hook (`project set --ci-overlap`) finds no shared steps: the CI gate records the receipt for the new base with both bases and the hook's output, and runs no local CI. Shared steps rerun alone through `ci.local.rerun_cmd` on the new merged tree. No hook, a failing or timed-out hook, bad output or an unknown step reruns everything and records why. The merge queue's refresh takes this path, and merge carries a `keep` receipt without running local CI.
