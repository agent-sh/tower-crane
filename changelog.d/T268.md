- Sandboxed codex agents can no longer reach the user's session bus or the docker socket. The codex profile read `/run` whole, and codex, with network on, does not block Unix socket connections, so any codex agent could run a command on the host with `systemd-run --user`, or talk to docker. The profile now hides `/run/user/<uid>`, `XDG_RUNTIME_DIR` and the docker and podman sockets, as claude's does. `sandbox.session_bus` now grants codex workers the bus socket as well.
