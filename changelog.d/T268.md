- Sandboxed claude and codex agents no longer reach the host's sockets under `/run`. Both sandboxes hide `/run` whole and give back only the DNS resolver directory and PATH directories there, plus the session bus socket when `sandbox.session_bus` is on. Before, a codex agent reached the session bus, so `systemd-run --user` ran commands on the host, and the docker socket; claude and codex agents both reached the system bus, snapd, systemd's varlink and journal sockets, sshd's local socket and others. `sandbox.session_bus` now grants codex workers the bus socket too.
- A sandboxed codex agent's `git push` over https gets its GitHub token again. The harness's command-scope `credential.helper` reset also cleared the trusted `credential.https://github.com.helper` spawn renders, and the git shim keeps that reset for codex on Linux, which sets no `CODEX_SANDBOX`.
