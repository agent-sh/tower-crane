- `hotfix ID --pr N` on a hotfix cancelled by a failure that was not the change's re-records it: the task returns to submitted at a new revision for `accept`, and its follow-up is cancelled with `superseded_by` and the `--reason` given. A claimed follow-up, or one with a branch, PR or commit, is refused, and dropping one with an owner ask is owner-required.
- A hotfix tests failure whose every failing name also fails at the merge's first parent is infrastructure: the hotfix stays submitted and opens no follow-up. The base rerun for a hotfix uses that first parent, since the newest main contains the merge.
