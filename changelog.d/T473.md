- On Windows, every lock-free read of the state files, the event log, its cuts file, progress files and the harness log waits out a sharing refusal (EPERM, EBUSY, EACCES) from a scanner or the indexer, with backoff, for up to 2 s. The supervisor no longer fails on a refused stat of `events.jsonl`.
- A refusal that outlasts the 2 s wait fails with its code, path and the wait it outlasted. It no longer reads as a removed state directory, which stopped the worker, or as an empty event log. Lock recovery no longer takes an event log it could not open for one without the commit's last event.
