- Tests evidence now binds configured host-only files and a digest of host environment settings for every task. Changing either makes earlier proof stale for acceptance and merge; projects with host settings must rerun their tests gate after upgrading. Standing publish policy additionally requires passing, non-skipped cases for every configured host-only file at the release head. The sandbox temp-directory fixture now supplies its own runtime directory, so both runtime and no-runtime branches run without depending on the caller's desktop session.
