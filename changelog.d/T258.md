- Codex workers start again when the user's home sits in a large directory. The codex profile named every entry of each directory above the home, and codex passes the profile to its sandbox as one argument, which Linux caps at 128 KiB: a home in a test's temp directory under `~/.cache` made it fail with `Argument list too long (os error 7)`. The profile now names the entries of `/` only, plus what the agent needs elsewhere outside the home and the install prefix of each `PATH` directory there, so it stays a few kilobytes. Other entries of the directories that hold the home, such as other users' homes, are hidden from codex agents. A `sandbox.read` path that holds the home, such as `/`, now refuses dispatch instead of being ignored.
