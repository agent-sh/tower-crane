- Sandbox masks name only paths the host has, so a masked path no longer leaves an empty read-only file behind. Worktree preparation, gate cleanup, stack sync and sandboxed git commands remove empty read-only lock files in the git directory (such as `.git/config.lock`) that no process holds, and log each removal, so a stale placeholder no longer blocks an upstream config write. A lock that a process of the same user holds with its files unreadable is kept, and cleanups run one at a time.
