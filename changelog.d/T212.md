- Sandboxed claude and codex dispatch refuses a `sandbox.write` or `sandbox.read` path inside the state's `homes/` or `brokers/` or the owner key directory. Such a path would reopen the agent homes, broker tokens or owner key under it.
- Dispatch also refuses a `sandbox.write` path that holds one of those directories, such as the state directory. In codex an agent could rename a directory above the store and move it out from under the next spawn's mask. A `sandbox.read` path that holds one stays allowed.
