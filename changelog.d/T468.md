- Projects declare broker verbs, fixed host actions a sandboxed worker runs for its task through the state broker instead of getting a docker or session bus socket. `project set --broker-verbs` (owner-required) records each verb's argv, source, mounts, resource caps, timeout, outputs and typed parameter patterns, and pins a commit source by copying its hash-checked git objects into the state directory.
- `task update --broker-verbs NAME,...` grants verbs to a task: delegated verbs are the orchestrator's to grant, others the owner's. `tower-crane verb NAME --param KEY=VALUE` runs a granted verb on the host from the pinned copy, under its caps and timeout, copies its declared outputs into the task scratch and records `verb` evidence with params, exit code, output digests and duration. Editing or committing the script in a worktree does not change what runs.
- A verb whose argv names a path an agent writes is refused, including a literal prefix before a placeholder, an `=` option value, a search path entry and a filled parameter value. Running `project set --broker-verbs` again with the same verbs repairs a damaged pinned copy.
