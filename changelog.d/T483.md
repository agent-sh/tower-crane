- A retained supervisor that runs out of memory while its keeper starts is reported as `resource-memory-max`. The OOM empties a systemd scope and the user manager removes it, counters included, within milliseconds, so a keeper that was still starting found nothing and the attempt ended without a reason. The launcher now keeps watching the scope's OOM counters until the keeper's watch is in place, and `containmentDone` resolves after that.
- The retained-supervisor late-limit tests no longer race the stop against a fixed completion time. The late probe starts once the keeper runs and keeps running until a stop ends it, so a Windows watchdog stop that takes a few CIM snapshots passes and a stop that never comes still fails.
