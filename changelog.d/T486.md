- On Windows, a contained agent's watchdog no longer takes another process's orphans into the agent's tree. Windows keeps an exited parent's pid on its children and gives that pid to new processes, so a harness that got the pid of an exited dispatch counted, and at its exit stopped, that dispatch's detached supervisor. That supervisor's agent then ran unsupervised: no live usage, no budget stop. A child now counts only if it started no earlier than the parent it names.
