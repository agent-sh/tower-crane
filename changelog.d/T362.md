- The harness hook tests no longer hang silently on a spawn that fails or stalls. A wait for a harness signal file ends once `spawn --wait` exits, and names all of spawn's output. A spawn still running when the runner aborts the test prints its output and is stopped. Before, a spawn that exited early left the test waiting 300 s for a ready file with no cause shown, and a spawn that never exited timed out the same way. A supervisor that misses its 10 s startup limit on a loaded runner is one way spawn can exit early.
