- Sandboxed workers, reviewers and researchers write a cache of their own, never the user cache root. `writeOutside: cache` granted all of `~/.cache` (or `XDG_CACHE_HOME`), where the installed tower-crane CLI, the broker, gate commands, spawn receipts and shared tool caches live, so one edit there ran code outside the sandbox. Each agent now gets `tower-crane/agents/<state hash>/<agent>` under the cache root, with `XDG_CACHE_HOME`, `GOCACHE`, `GOMODCACHE` and `npm_config_cache` pointing into it, removed with the agent's home. Removal restores write permission first, so the read-only module trees Go leaves in `GOMODCACHE` do not stop the next spawn.
