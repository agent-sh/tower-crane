- Automatic stack maintenance no longer delays `wait`'s signal handling. Stack
  linking, post-merge stack refresh, its base fetch and `gh stack sync` run
  their commands asynchronously. The first SIGTERM or SIGINT starts no further
  stack step; the second kills the running command. A sync that ran still
  records its outcome.
  Outside `wait`, as in `spend --from-spawn`, stack GitHub calls still run
  blocking, which keeps linking's unlocked window short.
