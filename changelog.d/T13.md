- Decision answers require an explicit owner identity or an agent the owner named on that decision. The orchestrator answers only decisions the owner marked technical, when the owner's `decision-delegation` project setting allows it. Other callers exit 1 naming who can answer, and each answer event records `answered_by` and the rule that authorized it. `decision delegate` is owner-only. `ci completed`, `ci webhook` and `wait` reactions run only for the owner or the orchestrator, so a worker that names its own identity cannot trigger gates or merges.
