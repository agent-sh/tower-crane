- A task whose workers exit 3 times without submitting at one revision is parked with `needs_owner` and a `respawn cap` event, so `wait` stops relaunching it. Outages, login failures, interrupts, budget stops and releases for an open decision do not count; an exit seen only as `worker-exited` after a monitor died does. `task show` prints the last worker's log tail; `owner-done` restarts the count.
- Worker spawn refuses a repository without an `origin` remote before it creates a worktree or starts a harness.
- `validate` warns when no harness program on PATH can run a worker or a reviewer, when an open task's tier cannot start, and when `gh auth status` fails or gh is missing. It asks for `gh auth login` only if the machine is online, since gh offline calls a stored token invalid.
