- The shell loop rule in the wait lint reads `$'...'` with its escaped quotes, keeps a `#` glued to `$(...)` as part of the word and no longer takes `<<` in `$((...))` as a heredoc, so none of them hides a loop. A sleep word in heredoc input or quoted text that a command such as `cat` or `grep` only reads, or that an assignment stores, no longer makes a counted loop sleep; text a shell runs still counts. Deeply nested unclosed quotes and substitutions no longer overflow the stack, and many unclosed heredocs are read in linear time.
