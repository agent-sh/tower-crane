- Git and gh that Tower Crane starts refuse to run while the repository's common directory holds a `commondir` file. A sandboxed worker can create one, and git in the main checkout then reads another repository's config, hooks, refs and objects, and Tower Crane that repository's state. The message names the file to remove.
- The supervisor watches the common directory and removes a `commondir` file as soon as it appears, records a `commondir removed` event, and checks again when the agent exits. The owner's own git that runs while the file exists is not covered (docs/ladder.md#the-common-directorys-commondir).
