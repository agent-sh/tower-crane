- Record already-merged hotfix PRs with `hotfix`, run software gates and independent review at their merge commits, and accept them as `accepted (hotfix)`. Confirmed failures create a follow-up rework task against the project base; pending checks and infrastructure errors stay retryable. Status and token bench counts identify accepted hotfixes separately. `hotfix` reconciles natively merged tasks too: `--sha` defaults to the PR merge commit, `--review` counts a clean-context review already posted on the PR, and `accept` records merge evidence at the merge commit without merging again.
