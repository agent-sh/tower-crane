- Git the CLI and gates start no longer runs a filter, diff or merge driver from a repository config file included through `includeIf`, whatever its condition. A `gitdir:` or `onbranch:` include that matched only in a task or gate worktree used to pass the config scan unseen. Git calls that read no object, index or hook (`rev-parse` locating the repository, `worktree list`, `prune`, `lock` and `unlock`, `remote get-url`) skip the scan, which cuts the scans on the spawn path from 116 to 18.
