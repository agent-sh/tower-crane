- State reads wait out a Windows sharing refusal (EPERM, EACCES or EBUSY) for up to 2 s, as state writes already did. Windows refuses to open a state file while another process renames a new copy over it. Before, a supervisor whose periodic read met that refusal failed with `supervisor failed: EPERM` and stopped its worker mid-edit, and a lock-free CLI read failed outright.
- The state compatibility drain tests no longer hang silently. Each wait ends once `spawn --wait` exits and names all of its output. A dispatch still running when the runner aborts the test prints the pending waits and its output, and its process tree is stopped. The shared `dispatch` test helper does this for any `spawn --wait` test.
