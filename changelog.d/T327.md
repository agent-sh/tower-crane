- The lock-free read fast path now checks the filesystem on macOS and Windows too. On macOS it runs only when the state directory's filesystem has the root's type number (APFS); SMB, NFS, AFP, WebDAV, FUSE and HFS+ mounts always compare the last line. Node reports only the number (statfs `f_type`), which macOS assigns as it registers filesystems, so the root is the reference and no process is spawned. On Windows a state directory on a UNC share, or a mapped drive that resolves to one, always compares. Other platforms always compare.
