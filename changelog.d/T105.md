- The board's write token reaches only the owner's browser. `serve --agent owner` prints a one-time link; only the page opened from it carries the token, which it keeps in the origin's local storage. A local process reading `/` or `/settings`, with or without an `Origin` header, gets an empty token and its POSTs are refused, so it can no longer answer the owner's decisions or set a rung command (review finding F4).
