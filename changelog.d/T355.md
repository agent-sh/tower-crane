- A rung moved to another harness drops each tool name the new harness does not know and keeps the rest. A claude rung with `tools: ["WebFetch"]` moved to codex no longer starts codex with `--enable WebFetch`, which codex refuses. `ladder harness` refuses a rung that follows the default when one of its tools is unknown there.
- A personal fallback that follows its rung's harness is checked when the rung moves. `ladder set` and `ladder harness` print a `notice:` for a route left naming a model the new harness cannot run, `ladder show` lists it as unable to run, and spawn skips it. The user file is not edited.
- The model check reads `opus[1m]` and other aliases with a context suffix as Claude aliases, no longer reads a Bedrock application inference profile ARN whose id starts with `o` and a digit as an OpenAI model, and keeps a Claude or Gemini model on a codex route whose provider is a custom one (OpenRouter, LiteLLM).
- The Settings page lists every drop and notice of a save under the form instead of reloading past them, and its last-change line names each rung of the newest save with what that rung dropped.
