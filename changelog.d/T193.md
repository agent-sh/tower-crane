- `task add --brief FILE` writes the task's brief in the same command, so the task can be dispatched without a second `brief set`. An unreadable file refuses the add and leaves no task behind.
- `inbox` lists a `brief_missing` item for each ready or rework task without a brief, with `brief set` as its resolving command. It replaces the task's `ready` or `rework_ready` item, since `spawn` refuses a task without a brief. `status` marks such tasks `(no brief)` (its JSON gives each ready task a `brief` flag), and the board marks them too.
