- Token-shape redaction no longer crashes on a long run. A prefix such as `ghp_`, `sk-` or `Authorization: Bearer ` before about 8 MiB of token characters threw a RangeError from the backtracking regular expressions: the tests, clean and local CI gates crashed instead of redacting their output, and a binary artifact stopped the artifact copy. Each shape is now a scan that reads each character a bounded number of times and redacts the run whole at any length. Every token the old expressions found is still redacted.
- A token glued to more word characters is redacted. `ghp_<token>_backup`, an AWS key followed by more letters and a Slack token followed by `_x` had no word boundary after the token, so the whole secret, or a Slack token's last part, stayed in the output. The token run is now redacted whole and the word after it stays.
