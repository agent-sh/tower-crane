- Token-shape redaction no longer crashes on a long run. A prefix such as `ghp_`, `sk-` or `Authorization: Bearer ` before about 8 MiB of token characters threw a RangeError from the backtracking regular expressions: the tests, clean and local CI gates crashed instead of redacting their output, and a binary artifact stopped the artifact copy. Each shape is now a scan that reads each character a bounded number of times and redacts the run whole at any length, with the same matches as before.
