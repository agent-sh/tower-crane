- A personal fallback route's `sandbox`, `env`, `env_file` and `scope` count only when `ladder set --fallbacks` wrote them under the authority check. That write pins a hash of each route's grants in `owner/route-grants.json` under the project's `owner_config_dir`. Spawn skips a fallback route whose grants were edited into the user file another way, and says so in its notices; `ladder show` lists the route with the command that approves it. Fallback routes without those fields work as before.
- A sandboxed claude agent gets `CLAUDE_CODE_TMPDIR` in its home, so claude keeps its own temp files (prompts, plugin staging, task output) where its commands can read but not write them. The commands keep `<TMPDIR>/claude-<uid>` in the agent's temp directory, beside claude's proxy sockets. Before, they shared one directory, and a command could plant files that claude reads back.
- A brokered agent's git shim sets `GIT_CONFIG_NOSYSTEM=1` itself, so the remote URLs it checks and the git it runs skip the system config, as spawn's read of the remote hosts does.
