- A reviewer that exits with code 0 and without review evidence no longer triggers a new reviewer at the same head and revision. Automation holds review dispatch until the head, the revision or a revuto thread changes, or the orchestrator runs `accept`. It records one `review held` event with the reviewer's last report or note, and the inbox lists a `review_held` item. Until the reviewer's exit receipt is written nothing is dispatched; a receipt missing past the rung's max retry backoff plus cleanup is reported once as `review exit missing` and the reviewer is replaced.
- `ci resolve COMMENT_ID --reason TEXT` posts the `[resolved]` reply on a revuto finding. Workers reach it through the state broker. The reason is capped at 1000 characters, cannot mention users and is signed with the author. The review ok refusal, the revuto rework reason and the worker skill name it.
- Revuto findings count only from logins named `revuto`, `revuto-<app>` or either with `[bot]`, not any login containing the name.
