- A spawn inside another agent no longer runs that agent's git shim for its supervisor's config scan. The scan skipped only the new agent's shims, so a placeholder cleanup the parent's shim waited on could still make the start miss its 10 s window. Empty PATH entries are skipped too, and a PATH with nothing left refuses the start instead of finding git in the agent's worktree.
- Startup-failed logs no longer pile up. Each kept or moved-aside one removes the task's older ones beyond the newest 5, as local CI keeps its runs, and is itself never the one removed.
- On macOS and other systems without `/proc`, the dispatch notices a supervisor that exits before it reports within about 100 ms, by asking `ps` for its zombie state, instead of waiting out the 10 s.
