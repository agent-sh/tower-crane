- `scripts/cache-proxy.js` is a local prompt-cache proxy in front of Bedrock. It logs per-request prefix hashes, cache reads and writes, cost and where a request diverges from the closest earlier one, without writing prompt text or reading credentials. It also has opt-in levers that make the provider's cache hit. docs/prompt-cache.md has the verdict and measurements. Medians of three: a Claude `--resume` turn reads 16.0k tokens instead of 1.9k once the user turn before Claude Code's trailing system message is marked, and a codex fork reads the parent's 18.4k instead of 0 with the parent's `prompt_cache_key`. Shared reviewer prefixes reuse cache across worktrees once volatile content moves out, the shared end is marked, and codex reviewers share one key. An added 1-hour breakpoint raises the 5-minute breakpoints before it, which Anthropic requires and which leaves the bill unchanged.
