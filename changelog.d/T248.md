- `inbox` and `wait --inbox` watch CI runs on the project base, at most once a minute and alongside the PR reads. A failed or cancelled push, schedule or dispatch run that no later run of its workflow turned green is a `main_ci_failed` item with its failing jobs and test names, and `status` prints it. A cancelled run with a newer run of its workflow counts as superseded. Later red runs of the same workflow refer to the open fix task. A test that fails again after a green run is a `main_ci_flaky` item that opens a flaky-test task or names the open one.
- A command timeout that comes due while the event loop was blocked no longer stops a child that already exited or was waiting on its full output pipe, and a timed-out gh read reports `timed out after N ms` instead of its partial output.
