- `inbox` and `wait --inbox` watch CI runs on the project base. A failed or cancelled push or schedule run that no later run of its workflow turned green is a `main_ci_failed` item with its failing jobs and test names, and `status` prints it. A cancelled run with a newer run of its workflow counts as superseded. A test that fails again in a later red base run is a `main_ci_flaky` item that opens a flaky-test task or names the open one.
