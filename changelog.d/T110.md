- Stack merges pin every accepted head with bottom-up `gh pr merge --merge --match-head-commit`. Merge commits preserve dependency ancestry so an upper PR can modify a file added below it without losing its merge base. A moved head, refusal or queued member stops the chain; only confirmed accepted members get successful merge evidence.
- CLI help and the orchestrator skill describe partial stack completion and recovery: inspect member evidence and PR states, resolve the blocker, sync idle members when needed, take changed heads through submission and gates again, then retry the target without merging confirmed lower members again.
