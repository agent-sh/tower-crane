- Gate commands (tests, proof, clean, local CI and the merge head check) and the git commands they run in the gate worktree, including its checkout hooks, run with `TMPDIR`, `TMP` and `TEMP` set to a directory under the gate temporary root, and the gate removes it with its worktree. Test helpers and the child processes they start no longer leave `tower-crane-*` directories in the system temporary directory.
- Test fixtures stop the processes they start in teardown even when the test fails before it reads their pids (the broker and supervision tests).
- A gate whose scratch directory cannot be created removes the temporary directory it had already made, instead of leaving it under the gate temporary root.
- The browser test helper starts Chrome from the first directory whose profile socket path fits (the temporary root, the system temporary directory, then the cache root), since a gate's temporary root can be too deep for it. The profile is still removed when the browser closes.
- Test fixtures and Chrome profiles that fail during setup are removed before the failure is reported, so an interrupted setup leaves nothing in the temporary root.
