- Tests receipts carry `phases`, the wall milliseconds of each step the gate ran (head, scoped proof, coverage, reverted run, base reruns, host probes and the total), so the gate's time can be read from its receipts.
- The tests gate runs its host-only commands beside the ordinary command of the head, scoped proof and coverage steps instead of after it. On this project the live sandbox tests took about 5 minutes of every gate after the suite had finished. The ordinary command's failure still decides the step and stops the host-only commands, a side that throws stops the other, and the step ends only after both have. The reverted run still starts its host-only commands only after its ordinary command passes.
- A gate command that starts while another command of the same gate runs is measured by the host governor through both process trees, not through the last command's scope alone.
