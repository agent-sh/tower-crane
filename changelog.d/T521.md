- With `tests.expensive`, the tests gate starts the scoped proof at head beside the head suite, in a worktree of its own, so its time overlaps the head. A scoped proof that does not pass there runs again alone after the head before it counts. The reverted run still runs alone, last, so two copies of a test clashing can never count as proof. A failing head stops the scoped proof beside it. Over the last 30 runs on this project the head was 91% of the gate's time, the scoped proof 5% and the reverted run 3%.
- Tests receipts carry `phases`, the wall milliseconds of each step that ran, so the gate's time can be read from its receipts.
