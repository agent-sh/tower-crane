- The tests gate no longer runs the scoped proof at head when a mapped or crucial head already ran every changed test through the same proof command. Over the last 30 runs on this project the head was 91% of the gate's time, the scoped proof 5% and the reverted run 3%.
- With `tests.expensive`, the reverted run starts beside the head in a worktree of its own, so its time overlaps the head. It counts only after the head passes; a failing head stops it.
- Tests receipts carry `phases`, the wall milliseconds of each step that ran, so the gate's time can be read from its receipts.
