- Tests receipts carry `phases`, the wall milliseconds of each step the gate ran (head, scoped proof, coverage, reverted run, base reruns, host probes and the total), so the gate's time can be read from its receipts. Over the last 30 runs on this project the head suite was 91% of the tests gate's time, the scoped proof 5%, the reverted run 3% and base reruns 1%.
