- Rework, interrupt and review prompts name the role skill by its absolute path in the installed package. They used to say `skills/tower-crane-work/SKILL.md`, a path a user's worktree does not have. The worker skill now lists the reviewer's checklist and blocking rules itself instead of pointing at the review skill's file.
- A spawned OpenCode agent may run `node scripts/check-shared-files.js` and `node scripts/cli-docs.js` only when the project has those files. They are this repository's checks and were allowed in every project.
- A corrupt or invalid state file now says to fix it by hand, using `events.jsonl`, or to restore a backup of the state directory. The old hint said to restore it from version control, but `init` keeps `.tower-crane/` out of git. An owner command on a corrupt `project.json` printed a raw stack trace; it now prints the same hint.
- revuto is optional. The README says what it is and where to get it, and the worker, reviewer and researcher instructions skip their revuto steps on a PR that has no revuto comments or check.
- README: the quickstart and the ladder table give the real tier rule (an `S` `docs` task is easy, anything else not `L` or research is medium), and the plugin's command list includes `/tower-crane-watch`, which the mod registers.
- The marketplace manifest drops `repository` and `keywords`, which `claude plugin validate` flagged as unknown fields. `plugin.json` keeps them.
