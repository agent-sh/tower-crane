- The orchestrator lease recognizes more session ancestors. A macOS login shell that `ps` names `-zsh` counts as a session shell, and so does `fish -i -C 'source x'`, whose `-C` value is no longer read as a script. `gemini`, `aider`, `goose` and `cursor-agent` count as harnesses, including Node and Python entrypoints. Other agent CLIs share their terminal shell's lease.
- Windows command lines follow CommandLineToArgvW for runs of quotes: `"a""b"` is `a"b`.
