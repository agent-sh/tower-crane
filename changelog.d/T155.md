- Worker merges through the git shim no longer fail when they bring in a path Claude's sandbox masks, such as a tracked `.mcp.json`. The shim builds the merge with plumbing and leaves the masked file as the sandbox gave it. It needs git 2.38 or newer, and refuses a masked merge that conflicts or uses an option it does not honour, with the reason.
- The root `.mcp.json` is tracked again, since the plugin's MCP declaration lives there. `check:shared` no longer refuses tracked paths the sandbox masks.
