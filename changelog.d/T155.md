- Worker merges and checkouts through the git shim no longer fail when they bring in a path Claude's sandbox masks, such as a tracked `.mcp.json`. Inside claude's sandbox the shim builds the move with plumbing and leaves the masked file as the sandbox gave it. A merge needs git 2.38 or newer. A checkout covers a branch or a revision, with `--detach`, `-b` or `-B`. A move that conflicts, has staged changes, or uses an option it does not honour is refused with the reason.
