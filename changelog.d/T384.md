- Scanning a binary local CI artifact uses far less memory. A 64 MiB file with a secret peaked at 1.3 to 1.5 GiB and now stays under 500 MiB. Positions found in a view are mapped back to bytes by a second pass, not by two 4-byte maps per byte, and the UTF-16 views run only when the file has a NUL byte or an environment value is not ASCII. `tokenMatches` can pass each match to a callback instead of returning a list, which held about 170 bytes per match.
