- Scanning a binary local CI artifact uses far less memory. A 64 MiB file peaked at 0.6 to 2 GiB and now stays under 460 MiB for ordinary content. Files packed with line-split tokens still reach about 0.8 GiB. Positions found in a view are mapped back to bytes by a second pass, not by two 4-byte maps per byte. The UTF-16 views run only when the file has a NUL byte or an environment value is not ASCII, and a UTF-16 view is first read as a one-byte probe, so one that shows nothing never becomes a string. `tokenMatches` and `valueSpans` can pass each match to a callback instead of returning a list, which held about 170 bytes per match.
