- Spend records price Bedrock and 1M-context Claude ids under their canonical model: `global.anthropic.claude-X`, `anthropic.claude-X` and `claude-X[1m]` match the `claude-X` price row. A run on several models records its primary model with each model's own counts, instead of one comma-joined id. Spend entries record `billing` (`api` or `subscription`), and `bench tokens` reports metered USD beside the list-price equivalent. `project set` refuses two price rows for one model that disagree. A resumed Claude run subtracts its baseline from each model's own counts, so earlier models are not priced again. A Claude rung that names no provider bills as `api` when its environment or the user's settings file turns on Bedrock.
