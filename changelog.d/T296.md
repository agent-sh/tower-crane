- A spawned OpenCode agent may run `node scripts/check-shared-files.js` and `node scripts/cli-docs.js` only when the project's main checkout has those files. A worker's own worktree no longer decides it, so the allowance exists only in projects that ship these scripts.
- A rework, interrupt or review prompt that names a role skill warns when the plugin root has no such file. Before, only an embedded or pi-loaded skill warned.
- The worker skill's inlined blocking list now matches the review skill's `What blocks` list word for word, and a test fails when they drift.
- README and `docs/ladder.md`: the `hard` rung runs `L` tasks other than research. `docs/ladder.md` also gives the real tier rule: an `S` task is easy only when its kind is `docs`, and `M` is not the only size that goes to medium.
