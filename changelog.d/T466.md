- On Windows, `scripts/mutants.js` runs each baseline and mutant in its own job object. A runaway hits the process cap inside the job, every descendant stops with the run, detached and orphaned ones included, and the run reports only once the job is empty. The old CIM snapshot watchdog lost orphans whose parents had exited, could adopt unrelated processes through a reused parent pid, and aborted the run on a single failed query. Surviving descendants could hold the test runner's output pipe and hang the Windows shard with no log.
- The mutation tests assert that no process a contained run started is still running when the run returns. The orphan test now runs on Windows as well, and the Windows repeat job runs `mutants.test.js` ten times in a row.
