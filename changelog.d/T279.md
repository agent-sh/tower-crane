- Stack sync and refresh refuse a member worktree with a rebase or merge in progress. A `gh stack sync` killed by a second signal or its timeout can leave a rebase that `git status` does not show; the refresh is now deferred with a reason naming it, instead of syncing or handing the worker that state.
- A drain during a spawn's stack refresh inside `wait` starts no agent. The spawn records `stack sync deferred` for its task, and the next wait refreshes the stack and dispatches it.
- Base resolution outside `wait` runs `git fetch` blocking again, like stack GitHub calls there. Only `wait` passes a signal that can stop it.
