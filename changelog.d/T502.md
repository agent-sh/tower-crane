- A test run in an agent's sandbox no longer deletes the agent's live broker socket. Process records name the recorder's pid namespace (`pidns`), and a pid recorded in another namespace, or checked by a caller that cannot read its own, is never judged exited. The broker sweep also keeps a directory whose socket still answers, whatever its owner record says. Six workers lost their broker this way and exited without submitting.
- `test/run.js` gives each run a private `XDG_RUNTIME_DIR` (`tct-XXXXXX` in the runtime directory, or in a sandbox's granted socket leaf) and removes it when the run ends.
- An agent that cannot reach its broker hears each address's error. Claude's sandbox has its own loopback, where the broker's TCP port always refuses, so the error used to name only `127.0.0.1:<port> (ECONNREFUSED)` and hid the socket's `ENOENT`.
